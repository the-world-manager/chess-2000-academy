| Проверка SQLite                                             | Закрытие и повторное открытие сервера не теряют профиль, PGN/FEN, заметку или сеанс; повторный вход тоже сохраняет данные           |

В основном браузерном сценарии необработанных ошибок JavaScript нет. Отказ сети в отдельном сценарии вызывается намеренно, чтобы проверить обработку ошибки. Скриншоты создаются в `test-results/`, не коммитятся.

Загрузка браузера с cdn.playwright.dev запрещена текущей сетевой политикой. Проверки выполнены системным Chromium без обхода проверки TLS; дополнительные сетевые разрешения для этого не нужны. Мобильный тест — эмуляция, физические устройства и Safari ещё не проверены.

Рабочая пользовательская база не заполнялась тестовыми аккаунтами или партиями. Тестовые базы изолированы во временных каталогах. Импорт, Stockfish, тренажёры, ежедневный план, отчёты, гибридный тренер и публикация Sites не проверялись как работающие: они ещё не реализованы.
