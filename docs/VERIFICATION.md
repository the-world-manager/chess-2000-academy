# Проверка подготовки Render Free + Neon Free

Дата: 23 октября 2026 года. Node.js 24.19.0, npm 11.9.0. Для тестов использована настоящая локальная PostgreSQL 18.4, без облачных ресурсов и оплаты.

| Проверка                                                    | Результат                                                                     |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `npm ci --cache /workspace/.npm-cache --no-audit --no-fund` | Установка по lockfile успешна                                                 |
| `npm run build`                                             | TypeScript и production-сборка успешны                                        |
| `npm test`                                                  | 12 тестов успешно, 0 ошибок/пропусков                                         |
| `npm run test:e2e`                                          | 4 браузерных теста на SQLite успешно                                          |
| `npm run test:postgres`                                     | 14 API/миграционных/процессных тестов PostgreSQL и 4 браузерных теста успешно |

**Всего 34 успешных выполнения тестов**, включая повторную проверку общих сценариев на разных базах. Исходные 7 серверных/шахматных и 4 браузерных теста сохранены и проходят. Некоторые исходные API-тесты выполняются повторно через PostgreSQL-адаптер — это не 34 разных функции продукта.

Проверено:

- Законность ходов, рокировка, запрет рокировки через шах, взятие на проходе, четыре вида превращения, мат и пат.
- Нотация, просмотр истории, обе ориентации доски, заметки, повторная загрузка и вход на настольном и мобильном Chromium.
- Реальная остановка и повторный запуск **отдельного production-процесса Node** с тем же PostgreSQL: позиция, заметка, профиль и сеанс сохранены. После выхода и нового входа данные также совпадают.
- Перенос непустой тестовой SQLite с профилем, исходным паролем, PGN/FEN, заметкой и сеансами. После переноса работает прежний пароль; сравниваются все поля. Байт-в-байт проверено сохранение исходного файла. Непустая целевая база не перезаписывается.
- Повторное применение миграций без потери записей; откат всей транзакции при ошибке внешнего ключа.
- Подготовка владельца из защищённых переменных, закрытие публичной регистрации, Secure/HttpOnly cookie за HTTPS-прокси, отказ запускать публичный сервер без владельца.
- Ограничение попыток входа после перезапуска, истечение сеансов и конфликт параллельных записей.
- Настройка обязательной проверки TLS для удалённой базы: параметры URL не отключают её. Реальный TLS-сеанс с Neon пока не проверен, поскольку доступ к Neon не предоставлен.
- `/api/health` не обращается к базе, `/api/ready` отдельно проверяет подключение. Пул не держит обязательные простаивающие соединения.
- Браузерный сценарий сетевого сбоя: русская ошибка, доска не меняется при неуспешном запросе, повтор после восстановления связи успешен. В обычном сценарии необработанных ошибок JavaScript нет.

Тестовые данные хранятся во временных изолированных базах. Реальная `data/academy.sqlite` сохранена, в ней на момент проверки 0 владельцев и 0 досок. Реальный пользовательский перенос не заявляется выполненным: в Neon ещё нет подключённой целевой базы.

Файлы доски, стилей и исходных браузерных тестов не изменялись. В UI исправлена только подпись типа хранения, чтобы не показывать SQLite при работе с PostgreSQL.

## Что не проверено в облаке

Не созданы и не опубликованы реальные Render/Neon ресурсы, нет проверенного адреса сайта. Отсутствуют `DATABASE_URL` и доступ к этим аккаунтам. Поэтому работа конкретного облачного подключения, тарификация аккаунтов, квоты и восстановление после перезапуска Render должны проверяться пользователем после подключения по [инструкции](RENDER_NEON_FREE.md).

Прямой запрос к render.com из этой среды блокируется сетевой политикой. Документация Neon о Free получена из официального репозитория `neondatabase/website`: 100 CU-часов, 1 ГБ/проект, 5 ГБ трафика/проект и приостановка при исчерпании бесплатных квот, а не автоматический платный апгрейд. Перед созданием всё равно требуется проверка Free/$0 в личной консоли; внешние условия могут меняться.

Sites/Workers/D1 в финальной архитектуре отсутствуют. Chess.com, Stockfish, тренажёры и гибридный тренер на этом шаге не разрабатывались и не выдаются за готовые.
