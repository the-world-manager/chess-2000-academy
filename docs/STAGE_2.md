# Второй этап: обновление существующего Render Free

Новые аккаунты, платные ресурсы и пароль Chess.com не нужны. Используются существующие Render Free и Neon Free. Приложение не включает платные тарифы и не выполняет запросы для предотвращения сна.

## Как обновить сайт

1. Откройте репозиторий GitHub `the-world-manager/chess-2000-academy`, вкладку **Commits** ветки `main`. Убедитесь, что последний коммит содержит второй этап.
2. Откройте панель Render и выберите **существующий** веб-сервис Academy. Не создавайте ещё один сервис или базу Render.
3. В **Settings** проверьте ветку `main`, тариф **Free**, Node.js 24.19.0. Команда сборки: `npm ci --include=dev && npm run build`. Команда запуска: `npm start`. Health Check: `/api/health`.
4. В **Environment** сохраните существующий `DATABASE_URL` Neon. Не публикуйте его и не заменяйте новой строкой без необходимости. Авторизация и пользователь не пересоздаются. Старые переменные первого запуска владельца не требуются, если профиль уже существует. `COOKIE_SECURE=true`, `NODE_ENV=production`, `HOST=0.0.0.0` сохраняются.
5. При необходимости сделайте собственную резервную копию PostgreSQL стандартным `pg_dump` на своём компьютере. Для этого не нужно покупать платный сервис резервирования. Старая SQLite, если она есть, не удаляется.
6. Нажмите **Manual Deploy → Deploy latest commit**. Дождитесь состояния **Live**. При запуске автоматически применится дополнительная миграция `002_games.sql` в транзакции. Она добавляет таблицы, не сбрасывая профиль, доску и заметки. Не выполняйте SQL-команды удаления или повторного заполнения базы.
7. Откройте сайт и обновите страницу с очисткой браузерного кэша. Войдите прежним логином и паролем. Проверьте прежнюю рабочую доску и заметки.
8. Откройте «Мои партии», оставьте **Rapid** и нажмите «Синхронизировать». Импорт идёт последовательно по месяцам, начиная с новых. Можно остановить после текущего месяца и продолжить позже. Повторное нажатие не создаёт дубликатов. Blitz импортируется отдельным выбором контроля.
9. Выберите партию. Просматривайте ходы стрелками/нотацией; мышью или пальцем можно разыгрывать локальные варианты. Кнопка возврата восстанавливает исходную партию.
10. Нажмите «Анализировать партию» (на телефоне откройте вкладку «Оценки»). Разрешите странице оставаться открытой до завершения. Доступны прогресс, остановка, график, лучшие варианты и ошибки. Если сохранение не удалось, используйте повторную попытку сохранения.
11. Выйдите и войдите снова: импортированные партии и сохранённый анализ должны открыться без повторного расчёта. Затем в Render можно один раз вручную перезапустить сервис и повторить эту проверку. Это проверка вашей облачной установки; автоматические тесты в репозитории проверяют отдельную настоящую локальную PostgreSQL.

Если Render не обновляется автоматически — это ожидаемо: в конфигурации выбран ручной deploy. При ошибке сборки смотрите журнал Deploy; при недоступности Neon — состояние проекта и квоту в Neon. Не включайте платный тариф для исправления ошибки. В журнале не публикуйте секреты.

## Что именно работает

Публичные профиль, статистика и архивы Chess.com используются без входа на Chess.com. В журнале есть дата, соперник, результат, цвет, рейтинги, контроль времени, проверяемый дебют и статус анализа. Фильтры Rapid/Blitz, точного контроля, дат, цвета и результата не смешивают статистику. Даты фильтрации интерпретируются по Москве.

Stockfish 19 Lite — настоящий бесплатный движок. Его JS/WASM загружаются с вашего сайта, вычисления идут в браузере, без нагрузки анализа на Render. Оценки даны с точки зрения белых; график ограничен ±10 пешками, мат выделяется отдельно. Варианты движка переводятся в шахматную нотацию. Причина ошибки описывается только в пределах подтверждённого расчёта; при отсутствии доказанного мотива объяснение нейтральное. Это не официальный Chess.com Game Review и не языковая модель.

Интерфейс сохраняет тёмную палитру Chess Performance и изумрудные акценты. Компоновка и управление приближены к привычному шахматному сайту: перетаскивание, подсветка ходов, доска рядом с панелью. На телефоне панели переключаются вкладками, чтобы основная доска помещалась в рабочую область. Длинные журналы и списки ошибок прокручиваются внутри панелей.

## Ограничения бесплатного варианта

- Render и Neon могут засыпать: первое открытие бывает медленным. Возможны ограничения бесплатных квот и временная недоступность. Приложение не предотвращает сон.
- Chess.com может ограничивать запросы или временно не отвечать. Ошибка отображается по-русски, уже сохранённые партии остаются доступны. Повторите вручную после указанной паузы. Полный первый импорт большой истории может занять несколько сеансов.
- Импортируются обычные шахматы Rapid или Blitz, не варианты. Некорректные PGN пропускаются с сообщением. Дебют не угадывается при отсутствии подходящих заголовков.
- Анализ ограничен 600 полуходами, одним потоком, Hash 16 МБ, глубиной до 14 и бюджетом 100/250/500 мс на позицию. Hash не является пределом всей памяти браузера. Облегчённая сеть и короткий поиск могут ошибаться. При необходимости повторите с 500 мс; совпадение с глубокой серверной оценкой не гарантируется.
- При очень коротком поиске движок может выполнить дополнительный ограниченный поиск глубины 1 для подтверждённой оценки. Придуманные значения не подставляются.
- При остановке сохраняется только рассчитанный префикс. Скрытие вкладки или уход со страницы останавливает вычисления; при уходе до сохранения последние результаты могут потеряться. Фонового анализа нет.
- Автоматически проверены desktop и mobile Chromium. Нужны современные WebAssembly и Web Worker; физические Safari/iOS и Firefox отдельно не проверялись.
- Весь исторический архив и каждая возможная ошибка внешнего API не проверены на реальных данных. Отчёт отделяет реальный импорт от искусственных тестовых примеров.
- Постоянные резервные копии на стороннем платном сервисе не настраиваются. Следите за бесплатной квотой Neon и делайте собственные копии.

Тренажёры и третий этап не разрабатывались. Подробности: [архитектура](ARCHITECTURE.md), [проверки](VERIFICATION.md), [лицензия движка](../THIRD_PARTY_NOTICES.md).
